# 0.0.2

本版修复保存后文档仍显示未保存的问题，并补齐阻塞诊断和按需文档清理。

## 保存与文档生命周期

- `save_document` 使用 `asCopy=false`，返回 Photoshop 实际 `dirty`、文档 id、落盘路径和关闭状态。
- `close_after_save:true` 仅在保存后确认文档干净时关闭；不会伪造 `doc.saved`。
- `export_as` 返回源文档的实际 dirty，区分副本导出与工作文档保存。
- 同路径打开默认复用；显式重载需要授权丢弃修改。保存和导出前创建、检查输出目录。
- 新增带整体未保存检查的 `close_all`，可限定目标文档。

## 阻塞恢复与工具组织

- 超时返回诊断并继续追踪原操作，禁止重复排队；原操作返回后由成功的 ping 确认恢复。
- Windows 模态窗口检测独立于 Photoshop 脚本队列；只确认白名单错误，未知、保存及覆盖窗口不自动点击。
- 按 Agent 保留懒加载，八个操作族合并相关入口，支持 replace 和卸载。完整合并目录 91 个，核心组 15 个，初始仅加载入口。
- 新增未保存内容像素采样、受限批处理和临时文档自检。修复背景层亮度调整与描边位置。
- 图标缩至 256×256，四角透明，83,304 字节，低于 DSH 元数据限制。

## 验证与边界

21 项 Node 回归测试通过。Windows Photoshop 2026 实测了重复打开、磁盘重写后复用、目录导出、采样、描边、自检、批处理、模态超时恢复，以及 PSD/PNG/JPEG 保存 dirty 回读与保存后关闭。未逐项验证所有上游工具；macOS、付费生成及所有自定义插件窗口不在本轮实测范围。

仓库另附白底转透明技能及 Python 回归测试，npm 包不包含技能目录，也不会自动安装技能。
